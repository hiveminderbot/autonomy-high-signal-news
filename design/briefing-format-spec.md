# Morning Briefing Format Specification

**Version:** 1.0.0  
**Created:** 2026-03-22  
**Applies to:** High-Signal News daily briefing generation

## Overview

This document defines the canonical format for morning briefings generated by the high-signal news aggregation pipeline. The format is designed for:

- **Quick consumption**: Readable in 5 minutes
- **Clear prioritization**: Visual signal indicators for importance
- **Cross-domain coverage**: AI, Software Development, and Investment news
- **Multiple output formats**: Markdown (primary), Plain text, HTML

---

## Format Principles

### 1. Five-Minute Read Constraint

| Section | Max Items | Target Read Time |
|---------|-----------|------------------|
| Header | 1 | 5 seconds |
| AI Section | 3-5 | 90 seconds |
| Software Section | 2-4 | 60 seconds |
| Investment Section | 2-4 | 60 seconds |
| Key Themes | 3-5 | 30 seconds |
| Footer | 1 | 5 seconds |
| **Total** | **15-20** | **~5 minutes** |

### 2. Visual Priority Indicators

| Indicator | Meaning | Usage |
|-----------|---------|-------|
| 🔥 | Breaking / Very High Signal | Major announcements, market-moving news |
| ⭐ | Important | Significant developments, noteworthy analysis |
| 📰 | Regular | Contextual information, supplementary stories |
| 📊 | Data/Analysis | Statistics, research findings, market data |

### 3. Content Tiers

Stories are categorized into three tiers based on relevance scoring:

- **must_read** (🔥): Essential information practitioners need today
- **important** (⭐): Significant developments worth knowing
- **contextual** (📰): Background information for completeness

## Section Specification

### Header

```markdown
# Morning Briefing - {Date}

*High-signal news for AI practitioners, software developers, and tech investors*
```

**Requirements:**
- Date in format: "March 22, 2026"
- Tagline must emphasize practitioner focus
- Horizontal rule separator follows

---

### Domain Sections

Each domain section (AI, Software, Investment) follows this structure:

```markdown
## {Emoji} {Domain Name}

{Indicator} **{Headline}** - {Subhead}
   Source: {Source Name} | [Read more]({URL})
   > {One-paragraph summary, max 50 words}
```

**Requirements:**
- Section header uses domain-specific emoji (🤖 AI, 💻 Software, 💰 Investment)
- Each story has priority indicator, headline, source with link, and summary
- Summary should be 1-2 sentences, max 50 words
- Stories ordered by priority (🔥 first, then ⭐, then 📰)
- Max 5 stories per section

---

### Key Themes Section

```markdown
## 🎯 Key Themes Today

| Theme | Stories | Signal |
|-------|---------|--------|
| **{Theme Name}** | {Story count} | {Brief description} |
```

**Requirements:**
- Synthesizes cross-domain patterns
- Max 5 themes
- Each theme has descriptive name, story count, and signal summary
- Stories may appear in multiple themes if relevant

---

### Methodology Note (Optional)

```markdown
## 🔍 Methodology Note

This briefing was generated using **{data sources}**:
- {Source 1} for {purpose}
- {Source 2} for {purpose}

**Quality:** {Quality indicator}
```

**Requirements:**
- Include only for real-time/generated briefings
- List data sources and their purposes
- Include quality indicator (verified current, aggregated, etc.)

---

### Footer

```markdown
---

*Generated: {Timestamp} | {Story count} stories from {Source count} sources*

**Priority indicators:** 🔥 Breaking / Very High Signal | ⭐ Important | 📰 Regular
```

**Requirements:**
- Timestamp in UTC
- Story count and source count
- Priority indicator legend

## Output Format Variants

### Markdown (Primary)

- Full formatting with emoji, links, tables
- Optimized for Obsidian and GitHub rendering
- File extension: `.md`

### Plain Text

- Emoji replaced with text indicators ([BREAKING], [IMPORTANT], [REGULAR])
- Links as footnotes or inline URLs
- Tables converted to simple lists
- Optimized for Telegram and email clients
- File extension: `.txt`

### HTML

- Full HTML with CSS classes for styling
- Responsive design for mobile/desktop
- Embedded in email templates
- File extension: `.html`

## Quality Checklist

Before publishing a briefing, verify:

- [ ] Total read time under 5 minutes
- [ ] No more than 5 stories per domain section
- [ ] All 🔥 stories genuinely breaking/major
- [ ] Headlines are descriptive (not clickbait)
- [ ] Summaries are 50 words or less
- [ ] All URLs are valid and reachable
- [ ] Source attribution is accurate
- [ ] Key themes synthesize actual patterns
- [ ] No duplicate stories across sections
- [ ] Timestamps and counts are accurate
